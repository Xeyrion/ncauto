# NCAuto · NovelCrafter 全量导入（非官方）

[English](README.md) · [技术文档](docs/technical.md)

![version](https://img.shields.io/badge/version-0.4.0-blue)
![platform](https://img.shields.io/badge/Tampermonkey-userscript-green)
![license](https://img.shields.io/badge/license-MIT-lightgrey)

NovelCrafter 官方仅提供数据导出（ZIP 归档），未提供相应的导入功能。
NCAuto 用于将官方导出的内容一次性写回目标书籍，覆盖 **Codex 条目
（正文、研究笔记、条目关联、别名、标签）、Snippets 与 Chats**。
面板语言自动跟随浏览器区域设置：`zh-*` 浏览器显示中文，其余显示英文。

## 功能特性

- **Codex 迁移**：完整保留条目正文、研究笔记、条目间关联、别名、标签与颜色。
- **Snippet 迁移**：纯文本正文自动转换为 ProseMirror/Tiptap 文档格式。
- **Chat 迁移**：按 `## User / ## AI` 标题重新分段，重建消息与对话线程。
- **写前权限预检**：当前账号对目标书籍无写权限时，在写入前即终止流程。
- **跳过重复项**：Codex 按名称、片段与对话按标题匹配，已有条目不会被修改。
- **试运行模式**：仅解析并预览，不发出任何写入请求。
- **面板可拖动、可最小化**，位置自动记忆。

## 安装步骤

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展。
2. 在 Tampermonkey 中新建脚本，将 `ncauto.user.js` 的全部内容粘贴进去并保存。
3. 打开当前账号下的一本书籍（网址形如 `app.novelcrafter.com/novels/xxxx/...`），
   右上角出现导入面板即表示安装成功。

脚本仅在 `https://app.novelcrafter.com/novels/*` 下运行，无需提供任何账号密码，
其复用的是浏览器中已建立的登录会话。

## 使用方法

### 第一步 —— 等待凭证就绪

面板初次加载时会显示正在等待凭证。请在页面内进行若干点击操作
（例如打开任意 Codex 条目），直至状态变为凭证已捕获。此步骤完成前，
导入按钮保持禁用。

### 第二步 —— 加载数据

点击「选 zip / JSON」或「选文件夹」。支持的输入如下：

| 输入                            | 说明                                                 |
| ----------------------------- | -------------------------------------------------- |
| 官方 `full.zip`                 | 完整项目导出，一次包含 Codex、Snippets 与 Chats                 |
| 官方 `codex.zip` / `chats.zip`  | 单类别导出                                              |
| 解压后的文件夹 / `codex_import.json` | 已解压的导出目录，或经 `tools/parse_codex_export.py` 转换的 JSON |

### 第三步 —— 勾选条目并试运行

1. 条目按 Codex / Snippets / Chats 分组，可整组或逐条勾选。
2. 先勾选「试运行」并开始导入，在日志中检查解析结果是否正确（此阶段不发出任何请求）。
3. 确认无误后，先实际导入 1～2 条并在书籍中核对，再执行全量导入。

### 第四步 —— 全量导入并验货

关闭「试运行」后开始导入，完成后**刷新页面**再核对数量
（侧边栏存在缓存延迟，以完成日志为准）。

## 选项说明

| 选项     | 默认值 | 说明                                                   |
| ------ | --- | ---------------------------------------------------- |
| 跳过重名   | 开启  | 名称或标题相同的已有条目将被跳过，不会被修改                               |
| 沿用导出ID | 关闭  | 导入同一账号的导出包时开启，可获得精确的关联映射；导入其他账号的导出包若出现 403，请关闭该选项后重试 |
| 间隔（毫秒） | 200 | 每次写入的间隔（另含随机抖动）；出现 HTTP 429 或大面积失败时请调大               |
| 试运行    | 关闭  | 仅解析并预览，不发出写入请求                                       |

## 常见问题

**面板持续显示等待凭证。**
请在页面内继续操作。脚本以被动方式从应用自身的网络请求中捕获凭证。

**提示未识别到 novelId。**
请确认已打开某本书籍内部的页面，且网址中包含 `/novels/xxx/`。

**出现 HTTP 403 FORBIDDEN。**
可能的原因：① 登录了错误的账号；② 目标书籍为他人只读分享；
③ 沿用了其他账号导出包中的 ID——请关闭「沿用导出ID」后重试单条。

**导入后侧边栏数量无变化。**
请先刷新页面。日志显示完成后即已写入，侧边栏不会实时刷新。

**日志中存在关联丢弃计数。**
属于正常现象。当某条关联的目标既不在本次导入范围内，
在书籍中又无同名条目时，该关联将被丢弃并计数。

**重复导入后出现 Snippet / Chat 副本。**
官方导出中仅保留其 ID 的前 8 位，导入时必须生成新 ID。
请开启「跳过重名」以按标题去重。

**突发大面积 HTTP 4xx 失败。**
最可能的原因是官方站点更新导致私有接口变更。
请提交 issue 并附脱敏后的日志（事先删除 JWT、userId、novelId）。
协议细节见 `docs/technical.md`。

## 实现原理

网页本质上是 API 的表现层。脚本不处理登录、不存储密码，
仅借用已登录会话，重放官网新建条目时发出的 `data.commit` /
`data.updateOne`（tRPC）请求。完整逆向记录见
[`docs/technical.md`](docs/technical.md)。
